量子コンピュータが速いのは、どんなとき？p.92

ユニタリ発展に利用するユニタリ行列のサイズが指数関数的に巨大になっても、量子コンピュータの計算時間への影響は古典コンピュータほど大きくなりません。そのため、量子コンピュータは指数関数的に巨大なユニタリ発展を高速に行えます。あらゆる行列計算を高速化できる訳ではなく、ユニタリ発展による高速なアルゴリズムが発見されている場合だけ高速化できます。― 教科書 p.92
💡 解釈
量子コンピュータでは、量子ゲートによる量子状態の操作が 2ⁿ×2ⁿ 行列のユニタリ変換 に対応する。
ユニタリ変換を効率的に実行できることと、古典コンピュータに対して計算上の優位性があることは別問題。
量子コンピュータが高速化を実現できるかどうかは、計算する問題の構造、効率的な量子アルゴリズム、そして 古典的な解法との計算量の比較 によって決まる。

  • 任意のユニタリ発展を近似的に実装できる ことが、理論的に分かっている
  • これは ソロベイ－キタエフの定理（Solovay–Kitaev theorem）として知られている
イメージ：決まった少しの種類のゲート を何個もつなげると、どんなユニタリ発展にも、いくらでも近づける
🤔 なぜ「ちょうど」ではなく「近似」なのか

SU(2n)ユニタリ行列は角度などの実数で連続に変わるので 非可算無限個
→ 回路の数が足りず、すべての U をちょうど作ることはできない → 近似 までしかできない

ソロベイ－キタエフの定理n 量子ビットでの厳密な主張（補足）

n 量子ビット（d = 2n）に作用する量子ゲートの 有限集合 𝒢 ⊂ SU(2n) が、次の 2 つを満たすとする
(i)逆元について閉じている：g ∈ 𝒢 ⇒ g† ∈ 𝒢
(ii)𝒢 が生成する群 ⟨𝒢⟩ が SU(2n) の中で 稠密
このとき、ある定数 c が存在して、任意の U ∈ SU(2n) と 任意の ε > 0 に対し、𝒢 の元の積
S = g1g2 ⋯ gℓ　（gi ∈ 𝒢）
で、次を満たすものが存在する
‖U − S‖ ≤ ε　かつ　ℓ = O(logc(1/ε))
※ 指数 c は次元によらない定数。O(·) に隠れた係数は次元に依存する
記号・用語
SU(2n)行列式が 1 の 2ⁿ×2ⁿ ユニタリ行列全体。全体にかかる位相（|z| = 1 の z）を除いた n 量子ビットのユニタリ発展
稠密どんな U に対しても、⟨𝒢⟩ の中に U にいくらでも近い元がある
‖U − S‖作用素ノルム。どの量子状態にかけても、U と S の結果のずれが ε 以下
cDawson–Nielsen の構成では c ≈ 3.97。一般のゲート集合での最良は c ≈ 1.44（Kuperberg 2023）。Clifford+T など特定のゲート集合では c = 1（最適）を達成
💡 ポイント：精度 ε を 10 倍細かく しても、必要なゲート数は log の多項式 でしか増えない → 任意のユニタリ発展を 効率よく 実装できる

ゲート集合が「生成する群」と「稠密」定理の条件 (ii) の意味

1
生成する群 ⟨𝒢⟩：𝒢 のゲートを 好きな順に、好きな個数 かけて作れる行列全体
⟨𝒢⟩ = { g1g2 ⋯ gℓ | gi ∈ 𝒢, ℓ = 0, 1, 2, … }
（逆元を含むので「群」になる：条件 (i)）
2
稠密：どんなユニタリ行列 U にも、⟨𝒢⟩ の中に いくらでも近い元 がある
∀U, ∀ε > 0, ∃S ∈ ⟨𝒢⟩ : ‖U − S‖ < ε
3
たとえ：有理数 は実数の中で稠密（どんな実数にも、いくらでも近い有理数がある）。ちょうど一致しなくても、近似なら必ずできる
右の例：円を一定の角度 α ずつ回す。α が 360° を割り切る と有限個の点しか作れない。α が 360° の無理数倍 だと、回すほど円が埋まる（稠密）

ユニタリ発展の可逆性3.4.3（p.93）

  • ユニタリ行列は 必ず逆行列を持つ（U†U = I なので U−1 = U†）
  • そのため、U|φ⟩ を U−1 でユニタリ発展させると
U−1U|φ⟩ = |φ⟩
  • となり、|φ⟩ に戻る。状態の変化に対して、元に戻す変化が可能 であることを 可逆（reversible）という
そのため、任意のユニタリ発展は可逆
いくつ続けても、逆順に U−1 をかければ元通り
※ X−1 = X（2 回かけると元に戻るゲート）。紫の線が行き、緑の太線が帰り（逆向きに回転）

区別できる例3.5・3.5.1（pp.94–95）

量子状態は測定しないと分からない。ただ、異なる 2 つの量子状態で |0⟩・|1⟩ を測定する確率が 同じになるケース がある

→ どちらも確率 1/2 で |0⟩、1/2 で |1⟩。このまま測定しても区別できない
※ |+⟩, |−⟩ はこの資料での略記
第4章の アダマール行列 H =1√2111−1 でユニタリ発展させると、測定で得る確率を変えられる
H|+⟩ = |0⟩H|−⟩ = |1⟩
H をかけた後で測定すると、|+⟩ は 確率 1 で |0⟩、|−⟩ は 確率 1 で |1⟩ → 区別できる！
