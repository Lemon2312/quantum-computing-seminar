# quantum-computing-seminar

『量子コンピュータの頭の中』のゼミ用スライド「古典ビットから量子ビットへ ― 論理ゲート・加算器から量子状態まで」（第2章 2.8〔pp.76–81〕＋ 全加算器の追加内容 ＋ 第3章 3.1〜3.2.1〔pp.84–87〕）。スライドの見出しに教科書の該当ページを記載しています。

## 使い方

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。外部ライブラリやネット接続は不要です。

| 操作 | キー |
| --- | --- |
| 次へ（箇条書きの表示 → 次のスライド） | → / Space / Enter / PageDown |
| 前へ | ← / Backspace / PageUp |
| 最初 / 最後 | Home / End |
| 全画面 | F |
| 一覧モード（全スライドをサムネイルで表示）の切り替え | O（戻るときは O / Esc） |

- 回路の青い丸（入力）をクリックすると 0 / 1 が切り替わり、信号（オレンジ = 1）が1段ずつ流れます。
- 真理値表の行をクリックすると、その入力が回路に入ります。回路のあるスライドは開くと自動再生が始まり、全パターンを順に表示します（「■ 停止」で止められます）。
- URL の `#番号` で特定のスライドを直接開けます（例: `index.html#15`）。
- **レーザーポインター（iPad + Apple Pencil）**：Apple Pencil のペン先を画面に当てている間、赤く光る点が表示され、なぞった軌跡が光ります。軌跡はペンを離してから約1秒で消え、消えきる前にもう一度ペンを当てると、それまでの軌跡も残り続けます（書き込みとしては残りません）。軽くタップしたときは回路の入力やボタンのクリックになります。
- ブラウザの印刷機能で PDF にすると、全スライドを箇条書きまで表示した状態で書き出せます（配布資料用）。
