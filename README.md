# quantum-computing-seminar

『量子コンピュータの頭の中』のゼミ用スライド「古典ビットから量子ビットへ ― 論理ゲート・加算器から量子状態・測定まで」（第2章 2.8〔pp.76–81〕＋ 全加算器の追加内容 ＋ 第3章 3.1〜3.3〔pp.84–91〕）。スライドの見出しに教科書の該当ページを記載しています。

## 使い方

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。外部ライブラリやネット接続は不要です。

| 操作 | キー |
| --- | --- |
| 次へ（箇条書きの表示 → 次のスライド） | → / Space / Enter / PageDown |
| 前へ | ← / Backspace / PageUp |
| 最初 / 最後 | Home / End |
| 全画面 | F |
| 一覧モード（全スライドをサムネイルで表示）の切り替え | O（戻るときは O / Esc） |
| 黒ペン ⇄ レーザーの切り替え / 書き込みを元に戻す | P / Z |

- 回路の青い丸（入力）をクリックすると 0 / 1 が切り替わり、信号（オレンジ = 1）が1段ずつ流れます。
- 真理値表の行をクリックすると、その入力が回路に入ります。回路のあるスライドは開くと自動再生が始まり、全パターンを順に表示します（「■ 停止」で止められます）。
- URL の `#番号` で特定のスライドを直接開けます（例: `index.html#15`）。
- **レーザーポインター（iPad + Apple Pencil）**：Apple Pencil のペン先を画面に当てている間、赤く光る点が表示され、なぞった軌跡が光ります。軌跡はペンを離してから約1秒で消え、消えきる前にもう一度ペンを当てると、それまでの軌跡も残り続けます（書き込みとしては残りません）。軽くタップしたときは回路の入力やボタンのクリックになります。
- **黒ペン（iPad + Apple Pencil）**：右上の道具で「✏️ 黒ペン」を選ぶと、Apple Pencil（パソコンではマウス）で黒い線を書き込めます。「🧽 消す」でなぞった線を消し、↩️ で元に戻し、🗑️ でそのスライドの書き込みを全部消します。「🔴 レーザー」に戻すとレーザーポインターになります。指では書かず、ペン先の軽いタップは回路やボタンのクリックになります。書き込みはスライドごとに残り、ページを再読み込みすると消えます。
- ブラウザの印刷機能で PDF にすると、全スライドを箇条書きまで表示した状態で書き出せます（配布資料用）。

## 構成

- タイトル / 本日の流れ
- **教科書 第2章「量子コンピュータ入門以前」の扉**
- **Part 1 論理ゲート**（扉スライド）
  - 古典回路とは（図2.13, p.76）
  - AND・OR・NOT・XOR（表2.3〜2.5 p.77・表2.7 p.80、図2.14〜2.16 p.78・図2.19 p.81）。「かつ／または／でない／一方だけ」という論理学的な意味で、ベン図とあわせて説明。XOR は 2 進数の足し算の 1 桁目（1 の位）の計算を表していることも説明
- **Part 2 半加算器：1ビット同士の足し算**（扉スライド）
  - 1ビットの筆算アニメーション（表2.6, p.79） → AND・OR・NOT（積・和・否定）版（図2.18, p.80）
  - XOR を使った半加算器の簡略化（図2.20, p.81）と、2つの半加算器のゲート数・段数の比較（p.81）
  - 【補足】基本論理ゲートごとのトランジスタ数・計算時間の違い
- **Part 3 全加算器：繰り上がりを受け取る足し算**【追加】（扉スライド）
  - 多ビットの筆算 → 全加算器の必要性
  - 全加算器の動く回路（半加算器×2＋OR）
  - リップルキャリー加算器（繰り上がりのさざ波加算器）
- 教科書 第2章の復習問題（5問。AND、半加算器・全加算器の役割、半加算器・全加算器の回路図の穴埋め。カードをクリックすると答えが出る）
- **教科書 第3章「量子コンピュータの基本ルール」の扉**
- **Part 4 量子ビット：量子状態と重ね合わせ**（扉スライド）
  - 量子ビット |0⟩, |1⟩ の定義（3.1・3.2, pp.84–85）
  - 量子状態の定義と状態ベクトル、集合 Q での書き方（pp.85–86）：スライダーで a, b を動かし、a|0⟩ + b|1⟩ を矢印の足し算で見ながら |a|² + |b|² = 1 かを確かめる。|a|², |b|² が測定で |0⟩, |1⟩ を得る確率になることを予告し、確率の横棒で表示
  - 【補足・教科書外】ブロッホ球：|ψ⟩ = cos(θ/2)|0⟩ + e^{iφ} sin(θ/2)|1⟩ を球面上の点として表す。θ, φ のスライダーと代表的な状態のボタンで球の上の点を動かし、測定確率の変化を見る
  - 内積 ⟨φ|φ⟩ を使った量子状態の表し方（pp.86–87）
- **Part 5 測定：計算結果を得る**（扉スライド）
  - 計算結果を得る「測定」（3.3・図3.1, p.88）：ボタンで測定し、|0⟩ / |1⟩ が確率的に得られる様子を見る
- 教科書 第3章の復習問題（5問。カードをクリックすると答えが出る）
