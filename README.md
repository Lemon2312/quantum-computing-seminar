## 使い方

`量子コンピュータゼミ/index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。外部ライブラリやネット接続は不要です。

| 操作 | キー |
| --- | --- |
| 次へ（箇条書きの表示 → 次のスライド） | → / Space / Enter / PageDown |
| 前へ | ← / Backspace / PageUp |
| 最初 / 最後 | Home / End |
| 全画面 | F |
| 一覧モード（全スライドをサムネイルで表示）の切り替え | O（戻るときは O / Esc） |
| 黒ペン ⇄ レーザーの切り替え / 書き込みを元に戻す | P / Z |

- 回路の青い丸（入力）をクリックすると 0 / 1 が切り替わり、信号（オレンジ = 1）が1段ずつ流れます。
- 真理値表の行をクリックすると、その入力が回路に入ります。回路のあるスライドは開くと自動再生が始まり、全パターンを順に表示します（「■ 停止」で止められます）。
- URL の `#番号` で特定のスライドを直接開けます（例: `index.html#15`）。
- **レーザーポインター（iPad + Apple Pencil）**：Apple Pencil のペン先を画面に当てている間、赤く光る点が表示され、なぞった軌跡が光ります。軌跡はペンを離してから約1秒で消え、消えきる前にもう一度ペンを当てると、それまでの軌跡も残り続けます（書き込みとしては残りません）。軽くタップしたときは回路の入力やボタンのクリックになります。
- **黒ペン（iPad + Apple Pencil）**：右上の道具で「✏️ 黒ペン」を選ぶと、Apple Pencil（パソコンではマウス）で黒い線を書き込めます。「🧽 消す」でなぞった線を消し、↩️ で元に戻し、🗑️ でそのスライドの書き込みを全部消します。「🔴 レーザー」に戻すとレーザーポインターになります。指では書かず、ペン先の軽いタップは回路やボタンのクリックになります。書き込みはスライドごとに残り、ページを再読み込みすると消えます。
- ブラウザの印刷機能で PDF にすると、全スライドを箇条書きまで表示した状態で書き出せます（配布資料用）。

## 圏論的量子情報ゼミ：『Quantum in Pictures』2.2「A spider bit me!」

`圏論的量子情報ゼミ/Quantum_in_Pictures_2.2.html`（全 20 枚）。図は左・文章は右、見出しはそのスライドの主張の文。動く図（COPY・CNOT の中で起きること・CNOT ＝ COPY ＋ ADD）は開くと自動再生し、「▶ 自動再生・◀・●・▶」で 1 ステップずつ進められる。それ以外は静止図。画面が狭いときは、右上の道具が文字に重ならないようにスライドを少し縮めて下げる。

- タイトル（目次 ＋ ビットの辞書の図）／ 2.2 のねらい：「量子ビットも状態と箱をしぼればビットとして使える」＋ビットの辞書（0・1・COPY・ADD・NOT・CNOT）
- **SECTION 1 ビットと「ビット状態」**：ふつうのコンピュータはビット（文字 → 0 と 1 の列）、2 つの状態だけを許す（赤 0° ＝ 0、赤 180° ＝ 1）、並べると 0 と 1 の列（教科書の例 10010）
- **SECTION 2 緑のクモ ＝ COPY**：0 も 1 もコピーする（入力が 0 と 1 の場合を並べ、同時に動かして比較。下に教科書と同じ静的な等式）
- **SECTION 3 赤のクモ ＝ ADD と NOT**：2 つのビットの融合（4 通り）、ADD 箱（1 + 1 = 0）、180° の赤 ＝ NOT 箱、ADD に 1 を差しこむと NOT
- **SECTION 4 CNOT ＝ COPY ＋ ADD**：CNOT の形、左が 0 ならそのまま・1 なら NOT（0 と 1 の場合を並べ、コピー → 融合を同時に動かして比較。下に静的な等式）、入力と出力の表、COPY と ADD への変形、いろいろな量子ゲート
- まとめ（左に各スライドの主張の文、右に 1・2 ページと同じビットの辞書の図）
