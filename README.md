# quantum-computing-seminar

『量子コンピュータの頭の中』のゼミ用スライド「論理式を実現する古典回路 ― 半加算器から全加算器へ」（第2章 2.8 ＋ 全加算器の追加内容）。

## 使い方

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。外部ライブラリやネット接続は不要です。

| 操作 | キー |
| --- | --- |
| 次へ（箇条書きの表示 → 次のスライド） | → / Space / Enter / PageDown |
| 前へ | ← / Backspace / PageUp |
| 最初 / 最後 | Home / End |
| 全画面 | F |

- 回路の青い丸（入力）をクリックすると 0 / 1 が切り替わり、信号（オレンジ = 1）が1段ずつ流れます。
- 真理値表の行をクリックすると、その入力が回路に入ります。「自動再生」で全パターンを順に表示します。
- URL の `#番号` で特定のスライドを直接開けます（例: `index.html#15`）。
- ブラウザの印刷機能で PDF にすると、全スライドを箇条書きまで表示した状態で書き出せます（配布資料用）。
