# 発表スライドの基本的な構成原則（調査メモ）

`SKILL.md` の「8. 発表スライドの基本原則」の根拠。2026-11 に調べた内容。
効果量などの数値は版・出典によって違うので、引用するときは原典を確認すること。

## 1. 視線の流れ：左上 → 右下

- 日本語の横書きや英語の資料では、見る人の視線は**左上から右下へ**動く（Z 型。文字の多いページでは F 型）。順番のある要素は、この流れに沿って並べると伝わりやすい。
- 見出し・図・太字は目を引きつける。視線が最初に止まる左側に、そのスライドの主役（図）を置く。
- **このゼミでの決まり**：タイトルスライド以外では、**図を左、文章を右**に置く。上下に並べるときは図を上にする。
- 注意：「図は左がよい」こと自体を直接確かめたスライドの実験は見つからなかった。根拠は、視線の流れの研究と「見てほしい順に並べる」という一般原則。

## 2. 1 スライド 1 メッセージ、見出しは「主張」（アサーション・エビデンス）

- Michael Alley（ペンシルベニア州立大学）の **アサーション・エビデンス** 型：見出しを話題名ではなく**言いたいことを述べる短い文**にし、本文は箇条書きではなく**図で裏づける**。
- 一般的な「話題名＋箇条書き」と比べた実験では、誤解が少なく、感じる負担が低く、時間がたってからの記憶もよかった（Garner, Alley ら 2009）。ただし研究の多くは同じグループによる。
- 例：「パンのレシピ」より「縦に積んだ箱 ＝ 時間の順番」。

## 3. マルチメディア学習の原則（Richard Mayer）

人が一度に処理できる量には限りがある。理解に関係ない処理を減らす原則が特に大事。

| 原則 | 内容 | スライドでどうするか |
|---|---|---|
| 一貫性（coherence） | 余計な語・図・飾りを除くと深く学べる（23 件中 23 件で支持、効果量の中央値 0.86） | 説明枠・注記・飾りを削る。迷ったら削る |
| 冗長性（redundancy） | 話している内容と同じ文を画面に重ねない（効果は小さめ） | 口で説明することを全文書かない。図の下の連動説明文を付けない |
| 信号化（signaling） | 強調・矢印・色で、大事なところと構造を示す | 強調は少数に絞る。色の意味をそろえる |
| 空間的近接（spatial contiguity） | 対応する言葉と図は近くに置く（9 件中 9 件、0.82） | ラベルは図の中・すぐ横に。離れた枠で図を説明しない |
| 時間的近接（temporal contiguity） | 言葉と動きは同時に示す | アニメーションは、その動きを説明しながら動かす |
| 区切り（segmenting） | 複雑な内容は小分けに示す | 段階表示は、順番が理解に効くときだけ使う |

（Mayer の原則は版によって 12 個・15 個などと数が違う。）

## 4. 絵の優位性（picture superiority）

- 言葉だけより、絵や図と一緒に示した内容のほうが思い出しやすい。理由の一つは、言葉と絵が別々に記憶されて手がかりが増えるため（二重符号化）。
- ただし、内容に直接関係する図でなければ効果は薄い。飾りの絵は一貫性の原則に反する。

## 5. 見た目の統一と余白

- 色・フォント・大きさ・位置をそろえると、聞き手の負担が減る。フォントは見出し用と本文用の 2 種類まで。
- 情報を詰め込みすぎず余白をとる。ただし余白が多すぎるのもよくない。
- 端ぎりぎりに置かず、要素の間隔をそろえる。
