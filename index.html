2.8 論理式を実現する古典回路

古典回路とは

  • 古典コンピュータは情報を 0 と 1 のビット で表現する
  • ビットに対する基本的な演算を組み合わせて
    古典回路（classical circuit）を構成し、計算を行う
  • 量子コンピュータも同様に、量子回路（quantum circuit）という形式で計算を表現する
  • → 古典回路の基礎を理解しておくと、量子回路の理解にも役立つ

ここから追加内容 ／ 全加算器

半加算器だけでは足りない？多ビットの筆算

4ビットの足し算 1011₂ (11) + 0111₂ (7) を筆算してみる

1桁目（最下位）は A₀ + B₀ の2入力
→ 半加算器で OK
2桁目以降は Ai + Bi + 下の桁からの桁上げ の 3入力
→ 半加算器では計算できない！
3つのビットを足して「和」と「桁上げ」を出す回路
＝ 全加算器（full adder）
追加内容 ／ 全加算器

全加算器の真理値表

入力：A, B, Cin（下の桁からの桁上げ）
出力：Cout（上の桁への桁上げ）, S（和）

S（和）：入力の 1 の個数が 奇数 のとき 1
S = A ⊕ B ⊕ Cin
Cout（桁上げ）：1 が 2個以上 のとき 1（多数決）
Cout = A·B + B·Cin + A·Cin
行をクリックするとハイライトされます
追加内容 ／ 全加算器

全加算器 ＝ 半加算器 × 2 ＋ OR

① 半加算器で A + B を計算
　→ 和 P = A ⊕ B、桁上げ A · B
② 半加算器で P + Cin を計算
　→ 和 S = P ⊕ Cin、桁上げ P · Cin
③ 2つの桁上げは 同時に 1 にならない（A·B = 1 なら P = 0）ので、OR でまとめれば良い
Cout = A·B + (A ⊕ B)·Cin
追加内容 ／ 全加算器

全加算器の回路を動かしてみる

ゲート5個（XOR×2, AND×2, OR×1）。S は 2段、Cout は 3段で確定します。
1 + 1 + 1 = 11₂ の行（入力すべて 1）を選んで、2つの半加算器の動きを確かめよう
追加内容 ／ 多ビット加算器

全加算器をつなげて 4ビット加算器リップルキャリー加算器

桁上げ C が 右（下位）から左（上位）へ波のように伝わる（ripple = さざ波）。n ビットなら最悪 n 個分の全加算器を順番に待つ必要がある → ビット数が増えると遅い
発展 ／ 量子回路への展望

量子回路で足し算するには？次章への予告

a, b をクリックして切り替え（計算基底 |0⟩, |1⟩ を入力した場合）
  • AND は出力が 0 だと入力が分からない → 不可逆
  • 量子回路のゲートは 可逆 でなければならない
  • CNOT：|a, b⟩ → |a, a⊕b⟩ … XOR の役割
  • トフォリ（CCNOT）：|a, b, c⟩ → |a, b, c⊕ab⟩
    c = 0 なら AND の役割
入力を残したまま計算できるので、半加算器・全加算器も量子回路で作れる。古典回路の考え方がそのまま活きる
Summary

まとめ

  • 古典回路は AND / OR / NOT などの基本演算（ゲート）を組み合わせて計算する。動作は 真理値表 で表せる
  • 半加算器：1ビット + 1ビット → 和 = A ⊕ B、桁上げ = A · B
  • 同じ結果を出す回路は複数ある。ゲート数・段数が少ない回路の方が速い（4個・3段 → 2個・1段）
  • 全加算器：下の桁からの桁上げを含む3入力の足し算。半加算器 × 2 + OR で作れる
    S = A ⊕ B ⊕ Cin,　Cout = A·B + (A ⊕ B)·Cin
  • 全加算器を並べれば 任意ビットの加算器 になる（リップルキャリー加算器）
  • 量子回路でも 可逆なゲート（CNOT・トフォリ） で同じ計算が実現できる
Discussion

演習・ディスカッションクリックで解答

Q1. 全加算器の和 S（A + B + Cin の下の桁）を XOR ゲートだけで作るには、XOR が何個必要？
2個。S = (A ⊕ B) ⊕ Cin。XOR は結合法則が成り立つので、順番に XOR していけば良い。
Q2. 4ビットのリップルキャリー加算器に必要なゲート数は？
全加算器 4個 × 5ゲート = 20個。最下位桁は桁上げ入力が無いので半加算器（2ゲート）にすれば 2 + 15 = 17個。
Q3. 全加算器の桁上げ Cout は Cin から何段で出る？ n ビット加算器ではどうなる？
Cin → AND → OR の 2段。n ビットでは桁上げが最大 n 個の全加算器を通るので約 2n 段。ビット数に比例して遅くなる。 改善策として、桁上げを先回りして計算する キャリールックアヘッド加算器 がある。
Q4. 引き算（A − B）を全加算器で行うにはどうすればよい？
2の補数を使う：B の各ビットを NOT で反転し、最下位の Cin に 1 を入れて加算すると A + (−B) = A − B になる。
