古典回路とは図2.13（p.76）

古典回路は、0と1の信号を使って計算する電子回路です。

  • コンピュータは、情報を0と1の組み合わせ（ビット列）で表します。
    数5 → 101 文字（ASCII）A → 01000001 スイッチOFF / ON → 0 / 1
  • AND・OR・NOTなどの基本的な演算を行う部品を「論理ゲート」と呼びます。
  • 論理ゲートを組み合わせることで、足し算や比較など、複雑な計算を実現できます。
つまり、古典回路とは「0と1を入力し、決められた計算を行い、0と1を出力する仕組み」です。

→ 半加算器では計算できない！

全加算器の回路を動かしてみる半加算器 × 2 ＋ OR

ゲート5個（XOR×2, AND×2, OR×1）。S は 2段、Cout は 3段で確定
S（和・この桁の出力ビット）：A と B を半加算した和 P を、さらに繰り上がり Cin と半加算した和 S = P ⊕ Cin = A ⊕ B ⊕ Cin
Cout（繰り上がりビット）：次のどちらかなら 1（OR でまとめる）
① A と B の半加算で 繰り上がりがあった（A·B = 1）→ そのまま Cout = 1
② A と B の半加算の和 P が 1 で、Cin も 1（半加算器②で繰り上がり）→ Cout = 1 Cout = A·B + P·Cin

  • 古典回路は AND / OR / NOT / XOR などの論理ゲートを組み合わせて計算する。動作は 真理値表 で表せる

    S = A ⊕ B ⊕ Cin,　Cout = A·B + (A ⊕ B)·Cin
  • 全加算器を並べれば 任意ビットの加算器 になる（リップルキャリー加算器）

量子状態定義（pp.85–86）

複素数 a, b が |a|² + |b|² = 1 という条件を満たすとき、
a|0⟩ + b|1⟩ の形をしたベクトルを 量子状態（quantum state）という
  • |a|, |b| は複素数の絶対値。難しく感じたら、実数の絶対値（符号をプラスにしたもの）をイメージ
  • 量子状態をベクトルの形で表したものを 状態ベクトル（state vector）という
ベクトルで書くと
a|0⟩ + b|1⟩ = a10+ b01=ab
同じ定義を集合で書くと（量子状態全体の集合 Q）
Q :={ab∈ ℂ²|a|² + |b|² = 1}
「複素数を成分とした2次元のベクトルで、|a|² + |b|² = 1 を満たすもの」

第3章 量子コンピュータの基本ルール ／ 3.2 量子ビット

内積を使って量子状態を表すpp.86–87

量子状態 |φ⟩ =ab∈ ℂ² の内積 ⟨φ|φ⟩ を計算すると

⟨φ|φ⟩ =a*b*ab
= a*a + b*b = |a|² + |b|²
a* は a の複素共役（内積は教科書 第2章を参照）
よって、量子状態全体の集合 Q は
Q = {|φ⟩ ∈ ℂ²⟨φ|φ⟩ = 1}
複素数を成分とした2次元ベクトル |φ⟩ が ⟨φ|φ⟩ = 1 という条件を満たすとき、|φ⟩ を 量子状態 という
前のページの定義と 同じ量子状態 を表している。
量子状態を表す方法はいくつかあるので、状況に応じて扱いやすい方法 を使う
第3章 量子コンピュータの基本ルール ／ 3.2.1 「重ね合わせ状態」とは？

「重ね合わせ状態」とは？3.2.1（p.87）

1√5|0⟩ +2√5|1⟩ のように、係数が 0 でない 複数の量子ビットの和で表される量子状態を 重ね合わせ状態（superposition）と呼ぶ
  • 1量子ビットの量子状態は、|0⟩ と |1⟩ という2種類の量子ビットの重ね合わせ状態を表せる
古典ビットは重ね合わせ状態にできない
→ 古典ビットと量子ビットで大きく異なる点
円をクリックすると点が動きます。※ 係数を実数に限った場合のイメージ図（横軸が |0⟩ の係数 a、縦軸が |1⟩ の係数 b）

まとめ第3章 量子コンピュータの基本ルール

  • 古典ビットの 0, 1 に対応する 量子ビット は、ベクトル |0⟩ =10,　|1⟩ =01 で定義される
  • 複素数 a, b が |a|² + |b|² = 1 を満たすとき、a|0⟩ + b|1⟩ を 量子状態 という。ベクトルで書いたものが 状態ベクトル
