2.8 論理式を実現する古典回路

古典回路とは図2.13（p.76）

  • 古典コンピュータは情報を 0 と 1 のビット で表現する
    数5 → 101 文字（ASCII）A → 01000001 スイッチOFF / ON → 0 / 1
  • ビットに対する基本的な演算を組み合わせて 古典回路（classical circuit）を構成し、計算を行う
  • 「古典回路はビット列からビット列への写像である。」by しむさん
  • このような、基本的な演算を組み合わせて計算を表現する 「回路」という考え方は、量子コンピュータにも共通する

教科書の比較は「1個のゲートの実行時間が同じ」という仮定の上での話。実際は、ゲートごとに 必要なトランジスタの数 も 計算時間 も違う

CHAPTER 3 追加

全加算器

繰り上がりを受け取る足し算

多ビットの筆算全加算器の回路リップルキャリー加算器
ここから追加内容 ／ 全加算器

半加算器だけでは足りない？多ビットの筆算

4ビットの足し算 1011₂ (11) + 0111₂ (7) を筆算してみる

1桁目（最下位）は A₀ + B₀ の2入力
→ 半加算器で OK
2桁目以降は Ai + Bi + 下の桁からの繰り上がり の 3入力
→ 半加算器では計算できない！
3つのビットを足して「和」と「繰り上がり」を出す回路
＝ 全加算器（full adder）
追加内容 ／ 全加算器

全加算器の回路を動かしてみる半加算器 × 2 ＋ OR

ゲート5個（XOR×2, AND×2, OR×1）。S は 2段、Cout は 3段で確定
S（和・この桁の出力ビット）：A と B を半加算した和 P を、さらに繰り上がり Cin と半加算した和 S = P ⊕ Cin = A ⊕ B ⊕ Cin
Cout（繰り上がりビット）：次のどちらかなら 1（OR でまとめる）
① A と B の半加算で 繰り上がりがあった（A·B = 1）→ そのまま Cout = 1
② A と B の半加算の和 P が 1 で、Cin も 1（半加算器②で繰り上がり）→ Cout = 1 Cout = A·B + P·Cin

Summary

まとめ

  • 古典回路は AND / OR / NOT / XOR などの基本演算（ゲート）を組み合わせて計算する。動作は 真理値表 で表せる
  • 半加算器：1ビット + 1ビット → 和 = A ⊕ B、繰り上がり = A · B
  • 同じ結果を出す回路は複数ある。
  • 実際の基本論理ゲートは、種類ごとに 必要なトランジスタの数や計算時間が違う
  • 全加算器：下の桁からの繰り上がりを含む3入力の足し算。半加算器 × 2 + OR で作れる
    S = A ⊕ B ⊕ Cin,　Cout = A·B + (A ⊕ B)·Cin
  • 全加算器を並べれば 任意ビットの加算器 になる（リップルキャリー加算器）
