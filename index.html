古典回路とは図2.13（p.76）

古典回路は、0と1の信号を使って計算する電子回路です。

  • コンピュータは、情報を0と1の組み合わせ（ビット列）で表します。
    数5 → 101 文字（ASCII）A → 01000001 スイッチOFF / ON → 0 / 1
  • AND・OR・NOTなどの基本的な演算を行う部品を「論理ゲート」と呼びます。
  • 論理ゲートを組み合わせることで、足し算や比較など、複雑な計算を実現できます。
つまり、古典回路とは「0と1を入力し、決められた計算を行い、0と1を出力する仕組み」です。

教科書の比較は「1個のゲートの実行時間が同じ」という仮定の上での話。実際は、ゲートごとに 必要なトランジスタの数 も 計算時間 も違う

実際の集積回路では、少ないトランジスタで作れる NAND・NOR を基本にすることが多い
量子コンピュータでも同じようなことが言える
実機の方式の違いや量子ゲートの種類などによって実行時間や誤りの起こりやすさが違う。量子回路の効率を考える場合でも「ゲートの数」だけでなく「どのゲートを何個使うか」「段数（深さ）」などでも評価する必要がある。

第3章 量子コンピュータの基本ルール ／ 3.2 量子ビット

量子状態定義（pp.85–86）

複素数 a, b が |a|² + |b|² = 1 という条件を満たすとき、a|0⟩ + b|1⟩ の形をしたベクトルを 量子状態（quantum state）という
a|0⟩ + b|1⟩ は |0⟩ と |1⟩ の重ね合わせ。a, b がどちらも 0 でないとき 重ね合わせ状態（superposition）という
📌 予告：|a|² は測定で |0⟩ を得る確率、|b|² は |1⟩ を得る確率
だから |a|² + |b|² = 1（確率を全部足すと 1）
  • |a|, |b| は複素数の絶対値（実数なら符号をプラスにしたもの）
  • 量子状態をベクトルの形で表したものを 状態ベクトル（state vector）という
集合で書くと（量子状態全体の集合 Q）
Q :={ab∈ ℂ²|a|² + |b|² = 1}
■ |0⟩ の確率　■ |1⟩ の確率　※ 係数を実数に限ったイメージ図
第3章 量子コンピュータの基本ルール ／ 補足（教科書外）

ブロッホ球補足（教科書外）

1量子ビットの量子状態は、2つの角度 θ（0〜180°）と φ（0〜360°）を使って
|ψ⟩ = cosθ2|0⟩ + eiφ sinθ2|1⟩
と書ける（全体にかかる位相は測定に影響しないので省く）
  • θ を緯度、φ を経度とみなすと、量子状態は 半径 1 の球面上の 1 点 になる → ブロッホ球
  • 北極が |0⟩、南極が |1⟩。その間はすべて |0⟩ と |1⟩ の重ね合わせ（赤道上は半々）
  • 高さ（θ）で測定確率が決まる：|0⟩ の確率 cos²(θ/2)、|1⟩ の確率 sin²(θ/2)。経度 φ（位相）は確率を変えない
■ |0⟩ の確率　■ |1⟩ の確率　|±⟩ = (|0⟩ ± |1⟩)/√2、|±i⟩ = (|0⟩ ± i|1⟩)/√2
第3章 量子コンピュータの基本ルール ／ 3.2 量子ビット

内積を使って量子状態を表すpp.86–87

量子状態 |φ⟩ =ab∈ ℂ² の内積 ⟨φ|φ⟩ を計算すると

⟨φ|φ⟩ =a*b*ab
= a*a + b*b = |a|² + |b|²
a* は a の複素共役（内積は教科書 第2章を参照）
よって、量子状態全体の集合 Q は
Q = {|φ⟩ ∈ ℂ²⟨φ|φ⟩ = 1}
複素数を成分とした2次元ベクトル |φ⟩ が ⟨φ|φ⟩ = 1 という条件を満たすとき、|φ⟩ を 量子状態 という
前のページの定義と 同じ量子状態 を表している。
量子状態を表す方法はいくつかあるので、状況に応じて扱いやすい方法 を使う

計算結果を得る「測定」3.3・図3.1（p.88）

  • 古典ビットを読み取ると、0 なら 0、1 なら 1 が返る。何回読み取っても同じ結果

  • これを読み取ると、|0⟩ が返ることも |1⟩ が返ることもある。何が返るかは毎回異なり、読み取るまで分からない
ただし、何が返るかは 確率で表せる
この読み取りのことを 測定（measurement）という
